PROJECT DETAILSAPRIL 2026

Payment Message Processing API

I built this project to deepen my understanding of ISO 20022, payment-message processing, and how payment systems work.

The API accepts mock payment instructions as JSON or simplified ISO 20022-style XML. It validates required fields and unique IDs, stores instructions in MySQL, and lets you retrieve and filter payments, request valid status transitions, and review each payment’s status-change history.

Processing simulates validation and execution, then marks a payment as completed or failed. This is a portfolio project only: it does not connect to banks or payment networks, and it does not move real money.
