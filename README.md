# Abhijeet Sawai — portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript. No build step or dependencies are required.

## GitHub Pages

This portfolio is published at [https://abhijeetsawai4.github.io/](https://abhijeetsawai4.github.io/) from this repository’s `main` branch and root folder. Push or commit changes to `main` to publish an updated version.

## Personalize further

1. Add your preferred short bio in the About section.
2. Expand the project descriptions with architecture, features, and your contributions; add repository or demo links if you want them public.
3. Replace the temporary GitHub profile links on each `SOURCE REPO` button with the correct repository URL.
4. Add a portrait or project screenshots by adding image elements to `index.html` and styling them in `styles.css`.
5. The Open Graph and Twitter metadata use `https://abhijeetsawai4.github.io/`. Update these URLs if you later change the site’s public address. The share image is `og-image.png` (1200 × 630); `generate_og_image.py` recreates it.

## Preview

Open `index.html` directly in a browser. The site is static and can be hosted on GitHub Pages, Netlify, or any static web host.
